# Miguel Flores — Game Developer Portfolio

A responsive static portfolio in English and Spanish with project galleries, itch.io links and a downloadable CV.

Published projects include Bubble Defender, a Unity game developed by the team in 32 hours for Global Game Jam 2025 and credited to Ghastt and Konamigue on its itch.io page. Miguel contributed as Game Designer & Developer and implemented aiming, enemy-damage handling and victory logic.

## GitHub Pages

Deployment target: `https://miguethelito.github.io/` from the `MigueTheLito/miguethelito.github.io` repository.

Publish the repository from the default branch and the repository root in **Settings → Pages**. The included `.nojekyll` file serves this as a plain static website. No package installation or build step is required.

## Local preview

Serve this directory with a static HTTP server, for example:

```powershell
python -m http.server 4391 --bind 127.0.0.1
```

## Editing

- `index.html`: English content and page structure.
- `app.js`: Spanish translation, project descriptions, galleries and interactions.
- `style.css`: responsive styling.
- `assets/`: project captures, local fonts, font licenses and the current downloadable CV.

Bossaball and Piratas Materos are identified as Unity/C# projects. Bossaball is an ongoing internship project with a public showcase planned after the internship.

Images come from Miguel's published itch.io pages. Screenshots do not claim individual authorship of every visual asset. Space Grotesk and Manrope are included with their SIL Open Font Licenses.
